МКР Рівень 1

1. try, catch, throw
try – містить код, де може виникнути помилка.
throw – генерує виняток.
catch – перехоплює та обробляє помилку.

2. Робота try–catch–throw
throw передає інформацію про помилку з try, а catch її обробляє та запобігає аварійному завершенню програми.

3. throw без try
Можна, але якщо виняток не буде перехоплено, програма завершиться аварійно.

4. Переваги введення-виведення C++
Типобезпечність, перевантаження операторів, підтримка об’єктів та зручне форматування через cin і cout.

5. Функції форматування
setw(), setprecision(), setfill(), fixed(), left(), right() — використовуються для вирівнювання та форматування чисел і тексту.

6. Factory Method
Фабрика приховує створення об’єктів і зменшує залежність клієнта від конкретних класів.

7. Dependency Injection
Залежності передаються ззовні через конструктор або методи, що спрощує тестування та заміну компонентів.

8. Visitor
Поява нового класу елементів потребує додавання нового методу Visit() у всіх Visitor.

МКР Рівень 2

1. Поділ великих інтерфейсів
Менші інтерфейси зручніші, бо клас реалізує лише потрібні методи.

2. Update у Observer
Через Update() передають повідомлення або дані про зміну стану об’єкта.

3. Стабільність ООП
Додавати нові операції простіше через поліморфізм, але нові типи можуть потребувати змін.

4. Рекурсивність Decorator
Декоратори можуть вкладатися один в одного та поступово розширювати функціональність.

5. Закон Деметри
Об’єкт повинен взаємодіяти лише з найближчими об’єктами — правило «не більше однієї крапки».

6. Патерни проектування
Породжувальні — створення об’єктів.
Структурні — побудова структури системи.
Поведінкові — взаємодія між об’єктами.

7. switch і поліморфізм
switch замінюють поліморфізмом, коли поведінка залежить від типу об’єкта.

8. Підходи програмування
Процедурний — функції працюють з даними окремо.
ООП — дані та методи об’єднані в класах.

МКР Рівень 3

1. Геометричні фігури
Створюється абстрактний клас Figure та похідні класи Triangle, Quadrilateral, Polygon з поліморфізмом.

2. Цифровий лічильник
Клас Counter з мінімумом, максимумом, збільшенням та автоматичним скиданням.

3. Шаблонний клас масиву
Клас для копіювання двовимірного масиву за рядками, стовпцями та діагоналлю.

4. Сума аргументів
Реалізація через перевантаження функцій, параметри за замовчуванням та змінну кількість параметрів.
